## Python Program

This program stores a student's name and a set of numbers. It prints the information and calculates the total using Python.

### Source Code

```python
name = "Your Name"
numbers = {18, 26, 3, 4, 5}

print("Student:", name)
print("Numbers:", numbers)
print("Total:", sum(numbers))
```

## Expected Output

The program displays the student's name, numbers, and total.

The total is **56**.
